#阶段一：准备阶段
##步骤1：确定文献
选定文献： Alves, H., Koch, A., & Unkelbach, C. (2018). [A Cognitive-Ecological Explanation of Intergroup Biases]. Psychological Science.

##步骤2：确定研究假设和样本
假设选取（遵循指南2.2.1的优先顺序）：
该文献包含3个实验。根据指南规定，如果该文献的假设均未经过可复现性检验，则应默认对最后一个实验（实验3）中的研究假设进行验证。
验证内容：复现实验3的核心假设。根据变量文件，实验3主要探讨在“共享积极/独特消极” vs “共享消极/独特积极”两种条件下，被试对不同群体的偏好（preference_first）与关联强度（phi）之间的关系。
样本选取（遵循指南2.2.2的原则）：
数据集： 优先查找并下载该文献在OSF（https://osf.io/qenhu/）上提供的原始数据。
样本量： 原则上不对样本量进行删改。若因原始数据庞大需调整，需使用G*power软件计算修改后样本量对应的效应量，确保达到80%的统计检验力。

##步骤3：数据预处理

操作： 下载原始数据后，对照原文献的方法部分，对原始数据进行完整的预处理。这包括但不限于：
根据实验条件（condition）进行数据分组。
计算或确认phi（phi系数）和preference_first等关键变量。
处理可能存在的缺失值。

记录： 在R代码中详细注释每一步预处理操作的理由和过程，并在最终报告的方法部分简述。
