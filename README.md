1.2 文献介绍（简要）

Luttrell等人（2016）提出，态度确定性（certainty）与矛盾性（ambivalence）对态度稳定性的影响并非独立主效应，而是交互作用：当矛盾性较低时，确定性增强稳定性（传统预期）；当矛盾性较高时，确定性反而加剧不稳定性（反转效应）。研究1以有机食品为对象，间隔1个月测量态度，通过回归分析验证了该交互作用。该文数据与代码已在OSF公开，适合进行计算可复现性检验。

2 方法

2.1 样本

使用原研究提供的 Study1Data.csv 文件。该文件包含492名T1被试，其中174名完成了T1和T2。本方案将使用这174名完整应答者的数据，与原分析完全一致。不进行任何样本删改。

2.2 原研究方法简介

研究设计：纵向观察（T1和T2间隔1个月）
测量变量：

态度：3个7点语义差异（bad-good, negative-positive, against-in favor）
确定性：Petrocelli等（2007）7项量表（4项清晰度+3项正确性）
客观矛盾性：分别评分正/负想法，使用相似-强度模型公式 [(P+N)/2] - |P-N|
主观矛盾性：3项冲突感受（conflicted, mixed, indecision）
数据分析方法：分层回归（Step1: 极端值 + 确定性 + 客观矛盾性；Step2: 加入交互项 确定性×客观矛盾性）
软件及包：原文使用R（版本未报告），关键包：tidyverse, broom, psych, lm()

2.3 重复思路说明

我们将完全遵循原研究的分析步骤，使用R语言（版本≥4.2）和相同的公开代码（经适当调整工作路径）重新运行回归模型。具体包括：
数据导入与变量计算：按照原代码计算态度均值（attT1, attT2）、态度改变量（change = abs(attT1-attT2)）、确定性总分、客观矛盾性、主观矛盾性、极端值（ex = abs(attT1-4)）。
描述性统计复现：计算样本量、各变量均值、标准差、相关系数，与原表1对比。
推断性统计复现：
主效应模型：lm(change ~ ex + amb + cert, data)
交互模型：lm(change ~ ex + amb * cert, data)
简单斜率分析：分别在高/低矛盾性（均值±1个SD）下检验确定性系数；在高/低确定性下检验矛盾性系数。
比较标准：采用百分误差（PE = |x_repro - x_orig|/|x_orig|×100%）对每个数值结果进行评级：
完全一致：PE=0%
次要偏差：0%<PE<10%
主要偏差：PE≥10%
推论一致性：比较原p值与复现p值是否在α=0.05同侧。
可选创新方法：
在完成上述原方法复现后，我们将额外使用 贝叶斯因子 分析（使用R包 BayesFactor）对同一交互作用进行检验，计算BF₁₀，并与原p值结论进行比较，以探讨不同统计框架下推论的一致性。
